# Juego de léxico sanitario

Aplicación interactiva para trabajar el léxico sanitario mediante un juego de parejas.

## Uso en el aula
- Repaso individual
- Actividad gamificada
- Competición entre alumnado

## Funcionamiento
El alumnado debe emparejar elementos léxicos con su significado.

Incluye:
- Diferentes niveles de dificultad
- Puntuación y porcentaje de acierto
- Pantalla final con repaso de términos
